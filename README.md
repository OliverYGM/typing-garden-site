# 键盘小乐园

选择任一入口，直接开始练习：

- **[Cloudflare 入口 →](https://typing-garden.pages.dev/)**
- **[GitHub Pages 入口 →](https://oliverygm.github.io/typing-garden-site/)**

给电脑初学者和小学生使用的键盘练习小游戏。使用电脑浏览器和实体键盘，打开网页后点击“开始挑战”即可练习。

## 三种玩法

- **气球打字**：按目标上的字符击破气球、星星和其他下落目标。
- **花园守卫**：按虫怪当前的键保护植物，使用空格、Enter 和连击奖励触发守卫技能。
- **打字闯关**：练习英文单词、短语，以及中文单字、词语、成语、歇后语、古诗和短文的拼音。

默认使用 2 分钟挑战、慢速、字母＋数字。可以调整时长、难度和练习按键，并在“声音与画面”中设置音量、天气及屏幕键盘。

中文拼音连续输入字母，省略声调和音节间的空格；ü 用 v。英文短语中的空格需要输入。

## 成绩保存

最近 200 局成绩只保存在当前浏览器中，不会上传到服务器。使用同一个浏览器和同一个网址查看；切换网址或浏览器不会自动迁移成绩，清除网站数据也会删除记录。

## 网站更新与离线使用

本仓库用于发布可运行的网页。Cloudflare Pages 和 GitHub Pages 均从本仓库的 `main` 分支发布网站，提交并推送更新后，两个平台会分别自动部署。部署成功后，可通过上方两个入口查看更新。

`index.html` 内嵌游戏代码、题库、图标和声音，可下载后直接在浏览器中打开并离线练习。文件方式下成绩保存受浏览器行为影响，需要稳定保留成绩时，建议固定使用上面其中一个在线网址。
